# คำถาม Setup และรูปแบบ answers.json

เป้าหมาย: ใช้บริบทและไฟล์ที่ให้มาก่อน ถามเฉพาะส่วนที่ยังขาด ไม่จำเป็นต้องครบทุกข้อหรือทุกขั้น
- ข้อที่เป็นตัวเลือกใช้เครื่องมือถามของโฮสต์เมื่อมี (Claude Code อาจชื่อ `AskUserQuestion`; Codex ใช้ชื่อที่มีจริง) หรือถามสั้น ๆ ในแชต ไม่เกิน 3–4 ข้อที่จำเป็นต่อรอบ ค่าแนะนำอยู่ข้อแรก
- ข้อที่ต้องพิมพ์เอง รวมถามในแชตทีเดียว
- ข้อที่ผู้ใช้ตอบไปแล้วในบทสนทนา ห้ามถามซ้ำ

## รอบ 1: แบรนด์และสินค้า (ถามในแชต)

- ชื่อแบรนด์/ร้าน (และชื่อภาษาอังกฤษสั้น ๆ ถ้ามี ใช้ตั้งชื่อ skill)
- สินค้าที่จะทำคลิป: ชื่อ ขนาด/รสชาติ ราคา/โปร (ถ้าอยากให้ขึ้นในคลิป)
- เอกสารสินค้า: รูปฉลาก/กล่อง ลิงก์หน้าร้าน ข้อความโบรชัวร์ (ใช้ทำ `products.md`)
- สิ่งที่ห้ามพูด/ห้ามโชว์ เช่น สินค้าอื่นในร้าน แบรนด์คู่แข่ง หน้าพนักงานบางคน

## รูปแบบงาน (ถามเฉพาะส่วนที่ยังไม่ทราบ)

| คำถาม | ตัวเลือก (ข้อแรก = แนะนำ) |
|---|---|
| ลงแพลตฟอร์มไหน | TikTok / Reels / Shorts / หลายที่ (9:16 เหมือนกัน) |
| ความยาวคลิป | 30–45 วิ / 15–30 วิ / 45–60 วิ |
| โหมดตัดต่อ | ตามงานที่สั่ง: แพ็กตัดต่อ / CapCut MCP เมื่อมีเครื่องมือที่รองรับ / แก้ Desktop Draft (ตรวจรูปแบบก่อน) |
| เสียงพากย์ | AI TTS (เช่น Google AI Studio) / TTS ใน CapCut / พากย์เอง / ไม่มีเสียงพากย์ |

## เสียง ภาพ และลิขสิทธิ์

| คำถาม | ตัวเลือก |
|---|---|
| เพลง/SFX | CC0 (freesound) + ไลบรารี CapCut / เฉพาะไลบรารี CapCut / มีเพลงที่ซื้อสิทธิ์แล้ว |
| มีม green screen | ไม่ใช้ / ใช้เฉพาะไฟล์ที่สิทธิ์ครอบคลุมการใช้งานนี้ |
| โทนแบรนด์ | สนุก ตลก / พรีเมียม เรียบหรู / อบอุ่น บ้าน ๆ / ให้เอเจนต์เสนอ |
| หน้าปิดท้าย (CTA) | "กดตะกร้าเลย" / "ทักแชต/สั่งในไลน์" / ข้อความอื่น (Other) |

## รอบ 4: ที่เก็บไฟล์ (ถามในแชต หรือ AskUserQuestion ถ้ามีตัวเลือกชัด)

- โฟลเดอร์งานจะให้อยู่ที่ไหน (ค่าแนะนำ: `Documents/<ชื่อแบรนด์>-clips`)
- ฟุตเทจอยู่ที่ไหน (ใส่ได้หลายโฟลเดอร์) หรือยังไม่ได้ถ่าย
- ใช้ CapCut บนเครื่องไหน (Windows / Mac) เวอร์ชันอะไร (ใช้ในโหมด CapCut เท่านั้น)

## answers.json

`scripts/setup_workspace.py` อ่านไฟล์นี้ ช่องที่ไม่รู้ให้ใส่ `""` หรือ `[]` ได้

```json
{
  "brand": "ชื่อแบรนด์",
  "slug": "brand-en",
  "content_type": "product",
  "platforms": ["TikTok", "Reels"],
  "format": "9:16, 1080x1920, 30-45 วิ",
  "mode": "plan",
  "voice": "เสียงที่ผู้ใช้ระบุ หรือเว้นว่างให้เลือกตามคอนเซปต์",
  "music_policy": "CC0 (freesound) + ไลบรารี CapCut",
  "meme_policy": "ไม่ใช้",
  "tone": "สนุก ตลก",
  "cta": "กดตะกร้าเลย ราคาสุดคุ้ม",
  "footage_roots": ["D:/footage/brand"],
  "capcut": {"os": "", "version": "", "draft_root": ""},
  "optional_tools": {"voice_conversion": "", "mascot": "", "motion_graphics": ""},
  "products": [
    {"id": "p1", "name": "ชื่อสินค้า", "size": "200 กรัม", "notes": "สั้น ๆ"}
  ],
  "never_show": ["สินค้าอื่นในร้าน", "แบรนด์อื่น"],
  "assumed": ["รายการค่าที่เอเจนต์สมมติแทนผู้ใช้"]
}
```

`mode` ใช้ค่าใดค่าหนึ่ง:
- `plan`: วางแผนแล้วตัดเอง
- `mcp`: ใช้ CapCut MCP ตาม tools/skills ที่ตรวจพบจริง (ไม่รับประกัน local PC Draft)
- `capcut`: ให้เอเจนต์แก้ Desktop Draft เมื่ออ่านรูปแบบได้และมีตัวอย่างที่ตรวจแล้ว
- `plan-then-capcut`: เริ่มแบบวางแผนก่อน ค่อยเปิดโหมด CapCut

`slug` ใช้ภาษาอังกฤษตัวเล็กกับขีด (`-`) เท่านั้น เพราะจะเป็นชื่อโฟลเดอร์ skill

`content_type` ใช้ `product` (ปริยาย) สำหรับแบรนด์สินค้า หรือ `general` สำหรับคลิปสอน/Screen Record งานทั่วไป โหมด general ไม่ต้องมี products; เก็บข้อเท็จจริง ขั้นตอน รุ่น และแหล่งอ้างอิงใน `brand/content-facts.md` แทนฉลากสินค้า `brand` ใช้ชื่อช่องหรือโปรเจกต์ได้

## หลังสัมภาษณ์
