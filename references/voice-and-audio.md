# เสียงพากย์ เพลง SFX และมีม

## เสียงพากย์ (TTS)

- ใช้เสียงและสไตล์ที่ผู้ใช้/แบรนด์ระบุ ถ้าไม่ได้กำหนดให้เลือกตามคอนเซปต์ จดเสียงลง concepts-log เพื่อทำงานต่อได้ ไม่บังคับเปลี่ยนเสียงทุกคลิป
- **คำสั่งสไตล์** ควรบอก 4 อย่าง:
  1. ใครพูด อยู่สถานการณ์ไหน
  2. อารมณ์
  3. จังหวะ เช่น "เว้นราวครึ่งวินาทีที่ '…'"
  4. บรรทัดสุดท้ายเป็น CTA แบบไหน
- **ระวังเรื่องจังหวะ**
  - สั่ง "ช้า ๆ เว้น 1 วินาที" อาจได้คลิปยาวเกิน
  - สั่ง "เร็ว ๆ" อาจสั้นจนไม่ถึง 30 วิ
  - ถ้าได้ยาวหรือสั้นผิดโจทย์ ให้ตรวจบท/ช่วงเงียบก่อน เลือกตัดบทหรือสร้างใหม่เท่าที่จำเป็น การปรับสปีดเล็กน้อยทำได้ตามงานแต่ต้องตรวจความเป็นธรรมชาติและหาเวลาใหม่
- **ตัวเลข** ให้เขียนเป็นคำอ่านในสคริปต์เสียง
- **บริการ TTS บนเว็บ** (เช่น Google AI Studio)
  - ใช้ผ่านเบราว์เซอร์ของผู้ใช้ที่ล็อกอินอยู่แล้ว
  - ถ้าเจนได้แล้วให้ใช้ผลเดิมก่อน ไม่กด Run ซ้ำเพราะดาวน์โหลดล้มเหลว ตรวจสถานะ/ดาวน์โหลดจากผลเดิม
  - ถ้าเครื่องมือเบราว์เซอร์ถูกปฏิเสธ ให้บอกข้อความจริงพร้อมหลักฐานที่เครื่องมือมีและขั้นที่ทำไม่ได้; ผู้ใช้เปิดเองได้ไม่ได้พิสูจน์ว่าเอเจนต์มีสิทธิ์ อย่าวนลองซ้ำโดยไม่มีการเปลี่ยนแปลง ถ้าสิทธิ์ไม่แก้ให้ทำบท/แพ็กต่อหรือรับไฟล์จากผู้ใช้
  - ใช้การอนุญาตเดิมในเซสชัน ถ้าต้องยอมรับเงื่อนไข/จ่ายเครดิต/ส่งข้อมูลที่ยังนอกขอบเขตค่อยขอเฉพาะส่วนนั้น
  - ใช้บริการเฉพาะงานเสียงที่ได้รับมอบหมาย

### หลังได้ไฟล์เสียง

1. **เก็บต้นฉบับและวัดความยาวจริง** ด้วย ffprobe ก่อนสร้าง timeline ตรวจว่าไฟล์เปิดได้ มีเสียง และเป็นผลที่ผู้ใช้ต้องการ จากนั้นปรับความดังแยกไฟล์; −16 LUFS เป็นค่าเริ่มต้นที่ปรับได้
   ```bash
   ffmpeg -i in.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 out_norm.wav
   ```
2. **หาเวลาของแต่ละบรรทัดจากไฟล์ที่จะใช้จริง** เพื่อวางช็อตและซับให้ตรง ถ้าแปลงเสียง/ตัดเสียง/ปรับสปีด ให้หาเวลาหลังขั้นนั้น
   - ทางง่าย: ใช้ช่วงเงียบ `ffmpeg -af silencedetect=noise=-38dB:d=0.25`
   - ทางแม่นกว่า: ใช้ ASR ที่ให้เวลารายคำ เช่น faster-whisper แล้วจับคู่ข้อความกับสคริปต์
   - ระวังตอน ASR เขียนตัวเลขเป็นเลขอารบิก ต้องแปลงเป็นคำก่อนเทียบกับสคริปต์
   - ถ้าคนพากย์พูดรวดเดียวไม่เว้นช่วง ระบบอัตโนมัติจะตัดผิด ให้ดูเวลารายคำแล้วกำหนดเวลาเอง
3. **ตรวจผล**
   - ทุกประโยคที่ใช้มีช่วงเวลา เรียงต่อกันโดยไม่ย้อนและอยู่ในความยาวไฟล์ ไม่มีค่าซ้ำหรือประโยคยาวที่ยุบเหลือไม่กี่มิลลิวินาที
   - ตรวจคำสะกดทับศัพท์ ตัวเลข และภาษาไทยก่อนจับคู่ข้อความ ช่วงที่ ASR หายให้ตรวจ/ถอดเฉพาะช่วง ไม่รันทั้งไฟล์ซ้ำโดยไม่จำเป็น
   - ฟังต้น/กลาง/ท้ายและรอยตัด ตรวจเสียงแตกและ peak ความยาว/คะแนนจับคู่ไม่ได้รับรองคุณภาพการฟังหรือความตรงของปาก

## การแปลงเป็นเสียงผู้ใช้ (ทางเลือก)

- ทำเมื่อผู้ใช้ร้องขอและมีสิทธิ์ใช้เสียงอ้างอิง ใช้ไฟล์ที่ให้มาและ environment/model ที่ตรวจพบ อย่าส่งเสียงอ้างอิงขึ้นบริการอื่นโดยเกินขอบเขตที่อนุญาต
- Seed-VC 44K เป็นตัวอย่าง backend ไม่ใช่ dependency บังคับ ตรวจ repo/CLI ของรุ่นที่ติดตั้งจริงก่อนตั้ง flags; คำว่า 44K ของโมเดลไม่จำเป็นต้องเท่ากับ sample rate ไฟล์ส่งออก
- เก็บ input/output แยกกัน บันทึกชื่อรุ่น ค่า config และ duration ใน manifest ภายใน workspace ตรวจการออกเสียง โทน และ clipping ใช้ผลที่ตรวจแล้วเป็นต้นทาง alignment
- ไม่มีโมเดลหรือ GPU ที่รองรับให้แจ้งข้อจำกัดและใช้เสียงเดิม/ทำแพ็กตามที่ผู้ใช้เลือก ไม่อ้างว่าแปลงแล้วเพราะเปลี่ยนชื่อไฟล์

## มาสคอตและ Motion Graphics (ทางเลือก)

- ใช้ mascot เมื่อผู้ใช้ให้/อนุญาต ระบุ pose และพาธจาก workspace อย่าฝังไฟล์ส่วนตัวใน skill สาธารณะ ตรวจ alpha, safe area และการวนคลิปให้พอดีความยาวเสียง
- ถ้าเป็นแค่ mouth loop/sway ให้รายงานตรง ๆ; lip sync ต้องมีขั้นตรงกับเสียงและตรวจจริง
- HyperFrames/Remotion เป็นทางเลือกภายนอกเมื่อเหมาะกับ motion ที่ต้องการ ใช้ skill/CLI docs ของรุ่นที่ตรวจพบ ไม่เดา API; สิ่งที่ CapCut ทำได้ตามเครื่องมือที่มีใช้ใน CapCut ก่อนเมื่อเป็นเป้าหมายของผู้ใช้

## BGM (เพลงพื้นหลัง)

- ให้เพลงเบากว่าเสียงพากย์ราว 13 dB ถ้าพากย์อยู่ที่ −16 LUFS ให้เพลงอยู่ราว −29 LUFS
- วัดความดังด้วย `tools/loudness.py เพลง.mp3` สคริปต์จะคำนวณค่า volume ให้
  - สูตรคือ `10 ** ((-29 - LUFS) / 20)`
- เลือกเพลงให้เข้ากับคอนเซปต์ เช่น ข่าว = จิงเกิลข่าว, มวย = เพลงสนามกีฬา
- คงเพลงประจำแบรนด์ได้ถ้าผู้ใช้ต้องการ ไม่เปลี่ยนเพลงเพียงเพื่อให้ต่างจากงานก่อน

## SFX (เสียงประกอบ)

- วาง SFX ตรงกับ "คำ" ที่พูด ไม่ใช่ตรงกลางบรรทัด เช่น เสียงถูก/ผิด ตอนพูดว่า "จริง!"
- ใช้ไม่เกินประมาณ 4–6 ครั้งต่อคลิป ถ้ามากกว่านี้จะรก
- เลือก asset ที่เหมาะกับงานและสิทธิ์ชัดเจน งานตัด/มิกซ์/แปลง/วิเคราะห์เสียงด้วยโค้ดทำได้ การใช้เสียงสังเคราะห์หรือบริการสร้างเสียงให้ยึดขอบเขตที่ผู้ใช้เลือก

## แหล่งเสียงและลิขสิทธิ์

ใช้ตามลำดับนี้ และจดทุกไฟล์ลง `assets/licences.md` (ชื่อไฟล์ ลิงก์ ไลเซนส์ วันที่โหลด)

| แหล่ง | ไลเซนส์ | หมายเหตุ |
|---|---|---|
| freesound.org (ตัวกรอง CC0) | ตรวจไลเซนส์ของไฟล์แต่ละรายการ | อย่าเหมารวมว่า Freesound ทุกไฟล์เป็น CC0 |
| ไลบรารีเพลง/SFX ใน CapCut | ตามเงื่อนไข CapCut | บางเพลงใช้เชิงพาณิชย์ไม่ได้ ให้เช็กป้าย |
| เพลงที่ผู้ใช้ซื้อสิทธิ์ | ตามสัญญา | เก็บหลักฐานการซื้อ |
| เว็บมีม green screen (เช่น creatorset) | ตรวจของแต่ละไฟล์และสิทธิ์ที่ผู้ใช้มี | personal-use ไม่พอสำหรับโฆษณาขายของ เลือกไฟล์ที่มีสิทธิ์ตรงงานหรือเว้นไว้ |

- เว็บที่มีระบบกันบอต/CAPTCHA ห้ามพยายามผ่าน ให้ใช้แหล่งอื่น
- หลีกเลี่ยงคลิปจากหนัง ทีวี เกม หรือหน้าคนดัง ใช้มีมสัตว์หรือสิ่งของแทน

## มีม green screen

- วางที่มุมจอ ขนาดเล็ก (ราว 30–50 % ของจอ) ห้ามบังหน้าคนหรือสินค้า
- **มีมหลายตัวขยับข้ามเฟรม** ต้องดูภาพนิ่งหลายจุดตลอดช่วงที่โผล่ ไม่ใช่แค่ภาพแรก
- บางไฟล์ตัวละครเล็กมากช่วงต้น ให้เริ่มจากวินาทีที่ตัวละครใหญ่พอ
- บางไฟล์ไม่ใช่ green screen จริง หรือมีซับฝังมาในภาพ ให้เช็กก่อนใช้ แล้วจดลง lessons
