# สแกนและจัดฟุตเทจ

## ทำไมต้องจัดก่อนตัด

ฟุตเทจขายของมักถ่ายรวดเดียวหลายสินค้า ในเฟรมจึงมีของอื่นปนอยู่บ่อย เช่น ขวดอีกรุ่นบนโต๊ะ ถุงขนมแบรนด์อื่น หรือกล้องแพนไปเจอจานอื่น ถ้าไม่จัดก่อน จะหลุดเข้าคลิปแบบที่ตอนตัดมองไม่เห็น แต่คนดูเห็น

## ขั้นตอน

1. **ทำดัชนี**
   ```bash
   python tools/footage_index.py "<โฟลเดอร์>" --out footage/index.json
   ```
   - ได้รายการไฟล์ทั้งหมด พร้อมรหัสสั้น ความยาว ขนาดภาพ fps และการหมุน
   - อ่านสรุปท้ายผล: ไฟล์ที่สั้นกว่า 2 วิ และรหัสที่ซ้ำกัน
2. **ทำ contact sheet**
   ```bash
   python tools/contact_sheets.py footage/index.json --out footage/sheets
   ```
   - ไฟล์ละ 4 ภาพที่ 10/35/60/85 % พร้อมเวลา แผ่นละ 10 ไฟล์
   - เปิดดูทุกแผ่น อย่าดูแค่ชื่อไฟล์
3. **จัดลง `footage/footage-map.md`** ทีละสินค้า
   - **ใช้ได้**: รหัส + สิ่งที่เห็น (เช่น "C0123 เทซอสลงถ้วย มือ+ขวด")
   - **ใช้ได้เฉพาะช่วง**: รหัส + ช่วงวินาทีที่สะอาด (ภาพนิ่ง 4 ภาพอาจพลาดช่วงกลาง ให้ดูเพิ่มด้วย `frame_check.py`)
   - **ต้องครอป**: รหัส + ระดับซูม/ตำแหน่งที่ทดสอบแล้ว
   - **ห้ามใช้**: รหัส + เหตุผล (หลายสินค้าในเฟรม แบรนด์อื่น ภาพเบลอ หน้าคนที่ไม่ได้ยินยอม)
   - **อาหาร/ฉากกลาง**: ช็อตที่ไม่มีสินค้าเลย ใช้ได้กับทุกสินค้า (เช่น ทอดเฟรนช์ฟรายส์) ให้แยกกลุ่มไว้
4. **ทดสอบการครอป**
   ```bash
   python tools/frame_check.py footage/check.jpg C0123:4.5 C0123:4.5:1.4:0:0.4
   ```
   - รูปแบบคือ `รหัส:วินาที[:ซูม:x:y]`
   - ซูม 1 = เต็มเฟรมเดิม
   - x, y เลื่อนภาพเป็นหน่วยครึ่งเฟรม: x > 0 เลื่อนไปทางขวาของภาพ, y > 0 เลื่อนไปทางล่างของภาพ
   - ดูผลแล้วจดค่าที่ใช้ได้ลง map

## กับดักที่เจอบ่อย

- **กล้องแพน/ซูมออกกลางเทค**: ต้นเทคสะอาด แต่ท้ายเทคเจอของอื่น จดช่วงเวลาให้แคบ
- **เทคสั้นกว่าช่วงที่ต้องการ**: ประโยคยาว 4 วิ แต่เทคยาว 3 วิ ให้แบ่งเป็น 2 ช็อต หรือหาเทคอื่น
- **ไฟล์หมุน**: กล้องตั้งแนวตั้งมักบันทึกเป็นแนวนอนแล้วติดค่า rotation ไว้ แอปตัดต่อหมุนให้เอง แต่สคริปต์บางตัวไม่หมุน ให้เช็กคอลัมน์ `rot` ใน index
- **ของแบรนด์อื่นบนชั้น/โต๊ะ**: ครอปออก หรือห้ามใช้
- **ฉากเดียวกันใช้ซ้ำทุกคลิป**: กระจายเทคให้ทั่ว แล้วจดลง concepts-log ว่าคลิปไหนใช้เทคหลักอะไร

## ถ้ายังไม่มีฟุตเทจ: รายการช็อตที่ควรถ่าย

ทำตารางให้ผู้ใช้ไปถ่าย แยกต่อสินค้า ถ่ายแนวตั้ง 4K หรือ 1080p ที่ 30/60 fps ถ่ายเผื่อหัว-ท้ายเทค 2 วิ แต่ละเทคให้มีสินค้าเดียวในเฟรม

| ช็อต | ทำไมต้องมี |
|---|---|
| ภาพสินค้าเดี่ยว ฉากสะอาด (หมุนรอบ, ยกขึ้น) | เปิดคลิป หรือบรรทัดที่บอกชื่อ/ขนาด |
| แกะ/เปิด/บีบ/เท สินค้าใกล้ ๆ | บรรทัดวิธีใช้ |
| เมนูที่ฉลากแนะนำ เมนูละ 2–3 เทค | บรรทัดเมนู |
| คนชิม/ใช้ แล้วยิ้ม/ทำหน้า (ยินยอมแล้ว) | บรรทัดความรู้สึก/รีแอกชัน |
| ด้านหลังฉลาก/วิธีเก็บ | บรรทัดวิธีเก็บ/คำเตือน |
| ฉากกลางไม่มีสินค้า (ปรุงอาหาร วัตถุดิบ) | ช็อตเชื่อม ใช้ได้ทุกสินค้า |
| ภาพสินค้าพื้นขาว (ภาพนิ่ง ไฟล์ PNG) | หน้าปิดท้าย / คัตเอาต์ |
