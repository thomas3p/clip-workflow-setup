# โหมดวางแผน: แพ็กงานให้ผู้ใช้ตัดเอง

ใช้เมื่อผู้ใช้ต้องการแพ็กไปตัดเอง หรือไม่มีช่องทางตัดต่อที่รองรับงาน เอเจนต์ทำสคริปต์และแผน ส่วนผู้ใช้ประกอบในแอป ฟีเจอร์นำเข้าซับ/ฟอนต์อาจต่างกันตามเวอร์ชัน

## ผลงานต่อ 1 คลิป

สร้างโฟลเดอร์ `projects/<วันที่>-<ชื่อรอบ>/<เลขคลิป>-<ชื่อสั้น>/` แล้วใส่ไฟล์ต่อไปนี้:

| ไฟล์ | เนื้อหา |
|---|---|
| `pack.md` | แพ็กงานตัดต่อ (จากเทมเพลต `assets/templates/production-pack.md`) |
| `vo_lines.txt` | สคริปต์เสียง บรรทัดละ 1 ประโยค (ตัวเลขเขียนเป็นคำอ่าน) |
| `voice_style.txt` | ชื่อเสียงและคำสั่งสไตล์ที่ใช้ในบริการ TTS |
| `vo.wav`, `vo_norm.wav`, `vo_times.json` | เมื่อมีเสียงจริง: ไฟล์เสียง และเวลาของแต่ละบรรทัด ถ้าสั่งเฉพาะสคริปต์ไม่ต้องสร้างเสียง |
| `captions.srt` | ซับตามเวลาเสียง ใช้นำเข้า CapCut ได้ (Text → นำเข้าคำบรรยาย) หรือคัดลอกทีละบรรทัด |
| `shots.csv` | ตารางช็อต: เวลาเริ่ม, ยาว, รหัสไฟล์, วินาทีในไฟล์, ซูม/ครอป, หมายเหตุ |
| `sfx/`, `bgm/` | ไฟล์เสียงประกอบที่โหลดมาแล้ว พร้อมจดที่มาลง `assets/licences.md` |

## ลำดับทำงาน

1. ทำคอนเซปต์และสคริปต์ตาม SKILL.md ถ้าผู้ใช้ขออนุมัติบทให้ส่งร่าง ถ้าสั่งทำให้จบแล้วให้ดำเนินต่อโดยไม่ถามซ้ำ
2. ทำเสียงพากย์และวัดเวลาจริงก่อนลงเวลาซับ/ช็อต ถ้ายังไม่มีเสียง ใช้เวลาอ่านคร่าว ๆ และระบุ `timing: estimated` ในแพ็ก ไม่เรียกเวลาเหล่านั้นว่า alignment ที่ตรวจแล้ว
3. จับคู่ช็อตจาก `footage-map.md` ลง `shots.csv` แล้วทำ `frame_check.py` ของช็อตที่ต้องครอป แนบรูปไว้ให้ดู
4. เขียนซับเป็น `.srt`
   - บรรทัดละไม่เกินประมาณ 18–22 ตัวอักษรไทย ไม่เกิน 3 บรรทัดต่อจอ
   - บอกคำไฮไลต์สีใน pack.md แยกจาก SRT; ไม่ใส่ Markdown `**` ลงซับที่นำเข้าเพราะอาจแสดงดอกจันจริง
5. ใส่จังหวะ SFX/BGM/มีม/เอฟเฟกต์ เป็นตารางเวลาใน `pack.md`
6. ทำหน้าปิดท้ายตาม style guide/โจทย์ ให้เวลาพออ่าน CTA ไม่บังคับโครงหน้าปิดท้ายถ้าผู้ใช้มีแบบแล้ว
7. ตรวจแพ็กเองก่อนส่ง:
   - ทุกบรรทัดมีช็อต
   - ไม่มีช็อตที่อยู่ในกลุ่มห้ามใช้
   - ข้อความทุกประโยคมีที่มาใน `products.md`
   - คลิปยาว ≥ ความยาวที่ตั้งไว้

## เมื่อผู้ใช้ตัดเสร็จแล้ว

ขอไฟล์ export (หรือพรีวิว) มาตรวจ:
- `tools/stills.py` ทำภาพนิ่งทุกประมาณ 1.25 วิ พร้อมจุดตัดสำคัญ แล้วตรวจตาม SKILL.md
- `tools/loudness.py` วัดความดังเสียงรวม

แจ้งจุดที่ต้องแก้เป็นวินาทีพร้อมวิธีแก้ เช่น "วิ 12.5 มีถุงขนมยี่ห้ออื่นที่ขอบซ้าย ครอปเป็น 130 %"
