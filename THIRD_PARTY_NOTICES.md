# Third-party components

The reusable workflow, templates and helpers in this repository are separate from the official CapCut plugin.

The local `vendor/CapCut/` snapshot was copied from the user's installed marketplace after upgrading to **0.2.5**. Its `.codex-plugin/plugin.json` declares **UNLICENSED**. This project does not grant redistribution rights to that snapshot or apply this project's MIT License to it. It is excluded from Git and the public release ZIP.

Obtain and install the official CapCut plugin through the [publisher's current installation instructions](https://sf16-sg.tiktokcdn.com/obj/eden-sg/962370eh7nupenuhbo/capcut_codex_plugin/SKILL.md). The downloaded installation runbook itself is not redistributed here.

Codex and Claude Code are separate products. Their names identify compatibility targets; this project is not an official distribution by OpenAI, Anthropic, or CapCut.

Python and FFmpeg are external prerequisites rather than bundled binaries. Pillow is optional and installed separately. Generated media, voice models, fonts, music, memes and customer footage retain their respective terms; record their sources and permitted use in the workspace's `assets/licences.md`.
